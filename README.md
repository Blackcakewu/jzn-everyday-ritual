# 日常一刻｜概念提案網站

「小時刻・大儀式」純前端概念網站。依照企劃書內容，將日常漢餅禮盒、情境選禮與客製祝福小卡轉化為可互動的單頁體驗。

網站中的舊振南品牌沿革、使命、產品名稱、商品內容、參考售價與攝影素材，取自[舊振南品牌官網](https://www.jzn.com.tw/)及[官方購物商城](https://shop.jzn.com.tw/zh-hant/products)。商品資料更新日期為 2026-10-29；實際售價、庫存與活動依官方商城為準。此專案為學生概念提案，並非舊振南官方網站。

## 本機預覽

直接開啟 `index.html`，或在此資料夾啟動任何靜態網站伺服器。

例如使用 Python：

```powershell
python -m http.server 8000
```

然後開啟 `http://localhost:8000`。

## GitHub Pages

網站不需要建置流程，之後可直接以儲存庫根目錄部署到 GitHub Pages。
